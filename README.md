## Что реализовано

- `Currency` — перечисление с кодами, символами и курсами из задания.
- `Balance` — неизменяемый `final` класс с `private final` полями, сложением, вычитанием и конвертацией. Каждая операция возвращает новый объект.
- `BankAccount` — счёт с объектом `Balance`, пополнением, снятием и переводами между счетами, в том числе в разных валютах.
- Дополнительные поля: владелец, лимит одного снятия/перевода, состояние блокировки. Есть методы блокировки и разблокировки.

- `Main` демонстрирует успешные операции, неизменяемость и обработку ошибок.
- `test/BankAccountTest.java` проверяет обычные и граничные случаи без дополнительных библиотек.

## Правила расчётов

Сумма хранится в `long`, в сотых долях валюты: для RUB это копейки, для USD и EUR — центы, для CNY — фэни. Например, `new Balance(10_000)` означает 100 рублей, а `new Balance(10_000, Currency.USD)` — 100 долларов. Конструктор с одним аргументом создаёт рублёвый баланс.

Курсы взяты именно из задания: 1 USD = 96 RUB, 1 EUR = 103 RUB, 1 CNY = 13.20 RUB. Это учебные фиксированные курсы.

При конвертации: `новая сумма = старая сумма × курс исходной валюты / курс целевой валюты`. Суммы до и после расчёта выражены в сотых долях соответствующей валюты. Округление — до ближайшей сотой доли, ровно половина округляется вверх (`HALF_UP`). `BigDecimal` используется только для расчёта, чтобы избежать погрешностей `double` и переполнения промежуточного произведения.

`Balance.add(0)` и `subtract(0)` допустимы и возвращают новые объекты. Банковские операции требуют строго положительной суммы. Лимит относится к каждой отдельной исходящей операции, а не к сумме за сутки. Нулевой лимит запрещает снятия и исходящие переводы. Заблокированный счёт не принимает и не отправляет деньги.

Если сумма перевода после конвертации округляется до нуля, перевод отклоняется. При ошибке ни один из двух балансов не меняется: оба новых баланса рассчитываются перед присваиванием. Это последовательная учебная программа; многопоточный доступ не реализован. Округление при повторных конвертациях может изменять сумму на сотые доли.

## Запуск

Нужен JDK 17 или новее (проверено на JDK 21). В IntelliJ IDEA откройте папку проекта, выберите установленный JDK, пометьте `src` как Sources Root при необходимости и запустите `Main.main()`.

Или в терминале из папки проекта:

```text
javac -encoding UTF-8 -d out src/Currency.java src/Balance.java src/BankAccount.java src/Main.java
java -cp out Main
```

Проверки:

```text
javac -encoding UTF-8 -cp out -d out test/BankAccountTest.java
java -cp out BankAccountTest
```

Проверка на JDK 21: компиляция с `-Xlint:all` без предупреждений, демонстрация запускается, все 94 проверки проходят.
